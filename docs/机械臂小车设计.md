# 机械臂小车设计
## 一.底盘驱动功能
### 功能描述

本模块通过两片 Drv8833 驱动芯片控制四个 TT 马达，驱动 X 形布置的麦克纳姆轮，实现前进、后退、左右平移、斜向移动与原地旋转等全向运动。

选型说明：

- 驱动方式：机械臂小车需要横移对准抓取位置，故采用麦克纳姆轮实现全向移动；收集小车只需前进转向，故用差速。
- 轮组布置：采用 X 形安装。X 形布置下横移时各轮侧向力对车体中心的力矩相互抵消，车身不易自旋、横移更稳定；机械臂小车需频繁横移对准抓取位置，故选 X 形。

### 开发历程

- 第1~2天：学习麦轮控制原理、直流电机原理，采购相关电机和驱动模块。
- 第3~4天：学习 SolidWorks 并建模相关 3D 打印零件；学习麦轮及 TT 马达的电子控制；学习电路连接。
- 第5天：调试麦轮的运动。
## 二.机械臂伸缩功能
### 功能描述

本模块为机械臂臂体部分，以大臂、小臂为基本结构，分别由舵机独立驱动。舵机接收主控板的角度指令，输出扭矩带动各关节转动，实现臂体抬升、俯仰、摆动、伸缩等姿态调整，精准控制机械臂的空间位置。

### 选型说明

- 驱动方式：大臂与小臂分别由一个舵机独立驱动，关节之间互不干扰。
- 大臂/小臂舵机：选用 MG996R。大臂与小臂负载较大，需要足够扭矩完成抬升与摆动，MG996R 为金属齿轮舵机、扭矩大，能稳定驱动。
- 小臂连杆结构：小臂通过连杆控制，构成平行连杆机构，使臂体末端在运动过程中姿态保持稳定。

### 开发历程

- 第1~2天：确定臂体结构与舵机选型（MG996R）。
- 第3~4天：完成臂体 SolidWorks 三维建模，提交机械结构件打印。
- 第5天~至今：等待 3D 打印成品
## 三.机械臂执行功能
### 功能描述

本模块为机械臂末端执行器，采用舵机驱动夹爪，接收主控指令完成夹紧与松开动作，实现对目标物体（能量块）的抓取。

### 选型说明

- 夹爪舵机：选用 SG90。夹爪仅需开合、负载小，SG90 微型舵机体积小、重量轻、扭矩足够，且能减轻机械臂末端重量。
- 夹爪结构：根据目标物体（能量块）的尺寸选择夹爪结构，保证夹取可靠。

### 开发历程

- 第1~2天：学习舵机工作原理与 PWM 控制方式；根据目标物体尺寸确定夹爪结构，完成舵机选型（SG90）。
- 第3~4天：完成机械爪零件建模，统计所需螺丝、舵机等零件并采购。
- 第5天~至今：等待 3D 打印成品
