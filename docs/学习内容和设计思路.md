# 设计思路
### 通过仔细阅读赛事规则，观察到低价值能量块（1分）的数量为偶数并且对称分布即比赛双方基本上都能获得同等数量，但高价值能量块（4分）的数量为奇数且除最中间的一个，其余都为对称分布。对此我们认识到最中间的能量块是制胜关键，故决定以获得高价值能量块为主要目标。达到这个目标需要机器人末端执行器拥有极高的灵活度以及精准的定位能力，故设计之一为机械臂小车并设计平行连杆结构和较小的小车地盘宽度来保证末端抓的够稳和能够顺利通过小桥；有考虑到机械臂小车收集方块困难且方块数量极多故需要高效收集的小车来收集地面上的能量块和机械臂小车从高台扔下的能量块，既保证工作效率又要能够过桥下故设计出了水车。整体的运行思路为机械臂小车先在高台上抓取能量块（竞争高能量块为首要目标）再丢到低地上由水车收集，然后机械臂小车下到低地和水车配合收集。
